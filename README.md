# ClawHUD

Experimental performance HUD for MSI Claw / Intel Arc.

## Phase 0

The project is currently validating whether a non-injected external HUD can coexist with:

- Windows 11 VRR
- Intel Arc
- OptiScaler
- XeFG

Development of production telemetry/UI features is blocked until this validation passes.

See [docs/PHASE0-VRR-POC.md](docs/PHASE0-VRR-POC.md) for the build and hardware-validation procedure.
